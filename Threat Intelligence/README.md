# Threat Intelligence Analysis of the Equifax Data Breach

## Overview

This project reconstructs the 2017 Equifax breach using the MITRE ATT&CK Framework.

The goal was to identify attacker behavior, map techniques to ATT&CK, and develop detection and mitigation recommendations.
