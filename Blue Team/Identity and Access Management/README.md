# Identity and Access Management

## Overview

This project explores the implementation and management of Identity and Access Management (IAM) using Microsoft Active Directory. It demonstrates how centralized authentication, authorization, user management, and security policies help protect enterprise environments while ensuring users have appropriate access to organizational resources.

- Organizational Units (OUs)
