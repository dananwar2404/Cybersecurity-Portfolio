# Email and Chat Forensics

## Overview

This project focuses on the forensic investigation of email communications and chat-based messaging platforms. It demonstrates techniques used to identify, preserve, and analyze digital evidence from electronic communications while maintaining forensic integrity.

---

## Skills Demonstrated

- Email Header Analysis
- Chat Log Investigation
- Digital Evidence Collection
- Metadata Analysis
- Chain of Custody
- Timeline Analysis
- Digital Investigations
