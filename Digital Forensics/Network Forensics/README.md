# Network Forensics

## Overview

This project examines techniques used to collect, analyze, and reconstruct network traffic during cybersecurity investigations to identify malicious activity and support incident response.

## Skills Demonstrated

- Network Traffic Investigation
- Wireshark
- Protocol Analysis
- Network Monitoring
