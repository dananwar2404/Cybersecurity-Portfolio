# Operating System Forensics

## Overview

This project explores forensic investigation techniques for both Windows and Linux operating systems. It demonstrates how investigators acquire, preserve, and analyze operating system artifacts to reconstruct user activity, identify malicious behavior, and recover digital evidence during cybersecurity investigations.

---

## Skills Demonstrated

- Windows Forensics
- Linux Forensics
- Operating System Analysis
- File System Investigation
- Registry Analysis
- Log Analysis
- Timeline Reconstruction
- Digital Evidence Collection
