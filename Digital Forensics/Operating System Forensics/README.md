# Operating System Forensics

## Overview

This project explores forensic investigation techniques for Windows and Linux operating systems. It demonstrates how investigators collect, preserve, and analyze operating system artifacts to reconstruct user activity, identify malicious behavior, and recover digital evidence during cybersecurity investigations.

---

## Skills Demonstrated

- Windows Forensics
- Linux Forensics
- Operating System Artifact Analysis
- File System Investigation
- User Activity Analysis
- Digital Evidence Collection
- Timeline Reconstruction
- Incident Investigation
