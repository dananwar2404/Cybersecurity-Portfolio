# Memory Forensics

## Overview

This project explores live memory acquisition and forensic analysis techniques used to identify malware, active processes, volatile artifacts, and evidence that disappears when a system is powered off.

---

## Skills Demonstrated

- Memory Acquisition
- Volatility Analysis
- Process Analysis
- Malware Detection
- Live Response
