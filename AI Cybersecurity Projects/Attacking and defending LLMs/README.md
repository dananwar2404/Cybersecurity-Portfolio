# 🤖 AI Security: Attacking and Defending Large Language Models

## Overview

This project explores the offensive and defensive aspects of securing Large Language Models (LLMs). Through a series of hands-on exercises, common AI attack techniques—including prompt injection, LLM jailbreaking, and data poisoning—were demonstrated and mitigated using layered defensive controls.

The project concludes with a professional AI security assessment documenting identified vulnerabilities, risk levels, and recommended mitigations.

## Project Workflow

1. Build a vulnerable AI chatbot.
2. Execute prompt injection attacks.
3. Perform LLM jailbreaking attempts.
4. Develop defensive controls using input validation and output filtering.
5. Execute a data poisoning attack against a spam classifier.
6. Measure the impact on model performance.
7. Produce a professional AI Security Assessment Report.
