# Offensive Operations

## Overview

These projects explore offensive security techniques used by penetration testers to evaluate the security of wireless networks, operating systems, and enterprise environments. The exercises demonstrate ethical hacking methodologies, wireless security attacks, exploitation techniques, and malware deployment within controlled lab environments.

## Skills Demonstrated

- Wireless Security Testing
- Penetration Testing
- Remote Exploitation
- Local Privilege Escalation
- Malware Deployment
- Offensive Security
- Vulnerability Assessment
- Ethical Hacking
